# github-notes

我的github的液态玻璃方案

## 液态玻璃材质实验台

在一片持续形变的三维流体上观察玻璃的透射与边缘折射，可切换为圆角矩形、极简玻璃收音机或极简玻璃磁带。流体在 Three.js 中以单张连通网格渲染。四种天气的天空、网格和天气粒子合成到同一张背景 Canvas，供六层玻璃与文字对比度采样使用。

### 运行

需要 pnpm 和 Node.js 20.19+（20.x），或 Node.js 22.12 及以上。在仓库根目录运行以下命令，打开终端显示的本地地址。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

构建会先运行 TypeScript 检查，再输出到 `dist/`。用预览命令检查构建产物。

```sh
pnpm build
pnpm preview
```

### 操作

- 舞台角落的四个图标切换天气，约两秒渐变。天气提供玻璃染色、环境光和表面效果，保留个人材质调节、观察角度及分层状态。雨天可在材质面板调整雨量和水滴滑落速度，下雪时可调节霜与冰花覆盖面积，浏览器会记住选择。
- 舞台右上角可暂停或播放动画，并复位调节参数。系统启用减少动态效果时，动画默认暂停，天气和分层即时切换。
- 在玻璃上按住鼠标并拖动可绕舞台中央旋转观察，六层随同一中心轴转动。触屏可直接拖动。聚焦玻璃后可用方向键旋转，按 `Home` 或双击恢复默认视角。
- 用「分层」和「合拢」切换视图，拖动「层间距」控制薄片的展开距离。点击列表里的层名或舞台上的薄片可查看该层说明与实时参数。「查看全部层」取消单层强调。
- 在材质区选择玻璃外观。切换时短暂淡出和淡入，保留天气、视角、材质、六层状态以及当前曲目的进度和音量。浏览器会记住所选外观，减少动态效果设置开启时立即切换。
- 在任意外观上点击文件夹，可导入本地音频或选曲。播放键切换播放和暂停，进度条可拖动跳转。圆角矩形可切换当前天气曲库中的上一首或下一首，收音机旋钮调节共享音量。项目没有预置歌曲，导入曲目只存储在当前浏览器。
- 「显示采样点」呈现文字对比度读取的 5×3 网格。

| 层 | 作用 |
| --- | --- |
| 01 Shadow / 投影 | 透明平面下方的柔和投影 |
| 02 Blur & light / 模糊与提亮 | 用轻微模糊、饱和度和亮度调节透射背景 |
| 03 Rim lens / 边缘折射 | 将背景沿边缘向内采样，偏移和色散向中央衰减 |
| 04 Tint / 染色 | 由天气和浓度参数决定的半透明色膜 |
| 05 Rim light / 边缘光 | 细窄的环境高光和内侧倒角，附着雨滴、水痕、薄霜或冰花 |
| 06 Ink / 文字与图标 | 随局部明度切换墨色的曲目信息、操作控件和线性结构 |

### 渲染与坐标

背景 Canvas 是呈现、折射和明度采样共用的源。六个 Three.js 平面共享固定旋转轴和透视摄像机。着色器使用各平面的投影矩阵把局部几何坐标映射到舞台，再换算成原始背景纹理坐标。模糊层读取自身投影处的背景，折射层读取沿轮廓法线偏移后的纹理，保留边缘以内的中心透射。合拢时各层共面并露出一圈立体侧壁，分层时沿局部深度轴展开。染色、边缘光、投影和文字各自叠加。

文字层从标题和副标题下方的 15 个投影点读样，剔除亮度极值后，根据天气色膜与透射亮度估算文字对比度。文字明暗切换有阈值缓冲。玻璃染色、饱和度和亮度由天气参数及材质滑杆确定，透射和折射由实时背景纹理提供。三种机身共用圆角矩形距离函数和实际尺寸，用于六层遮罩、边缘法线和阴影。

液体是单张共有顶点的索引网格。统一形变场每帧更新顶点高度并重新计算网格法线。透视摄像机从斜上方看向表面，深度缓冲让更近的隆起自然遮住后面的凹陷。高光、明暗和远处的雾色由位置、法线及视线计算。天空和天气粒子与网格合成之后，再用这一帧更新玻璃的背景纹理。WebGL 2 不可用时仍显示天空与天气粒子。

玻璃上的雨滴、霜与冰花使用实际轮廓和玻璃局部坐标，在边缘光平面投影。覆盖率以轮廓内部的面积为分母，冰花从真实边缘朝内生长。雨水以固定时间步更新独立水段的水量、速度和轨迹，在表面差异与既有湿痕的作用下流动。接触汇合与局部分流分配水量。水段和残余薄膜写入玻璃局部厚度场与湿润度场，厚度斜率驱动同一背景的局部折射和环境高光。雨水模拟与音乐输入独立。设备资源有限时优先降低背景分辨率和粒子密度，玻璃保留独立的绘制分辨率。

### 检查流体形态

开发服务默认显示正常材质。暂停背景后，可在控制台切换同一帧的线框、侧视和正常视图。线框和侧视都沿用同一份网格数据。也可以在开发服务的 URL 加上 `?fluidView=wireframe` 或 `?fluidView=side` 直接进入检查视图。

```js
window.dispatchEvent(new CustomEvent('glass-lab:fluid-view', { detail: 'wireframe' }))
window.dispatchEvent(new CustomEvent('glass-lab:fluid-view', { detail: 'side' }))
window.dispatchEvent(new CustomEvent('glass-lab:fluid-view', { detail: 'normal' }))
```

### 音乐能量接口

播放器把归一化分析值送入同一个形变场。低频调节整片网格的起伏振幅，中频轻微改变曲面弯曲，总能量调节向右流速。流速随时间积分，切换或暂停音乐时，相位不会跳回初始值，包络会逐渐回到天气的基础流动速度。开发时也可调用 `setMusicEnergy({ low, mid, high, energy })` 模拟输入，`setMusicEnergy()` 清空目标值。

开发服务中可从浏览器控制台模拟输入，先确认背景处于播放状态。

```js
window.dispatchEvent(new CustomEvent('glass-lab:music-energy', {
  detail: { low: 0.85, mid: 0.45, high: 0.35, energy: 0.8 },
}))
window.dispatchEvent(new Event('glass-lab:music-energy'))
```

### 后续扩展

- **天气**在 `src/climate.ts` 调整基础状态，在 `src/background.ts` 增加远景光影和粒子。玻璃表面效果在 `src/surfaceWeather.ts` 中扩展。
- **播放器清晰区**在 `src/playerLayout.ts` 中定义。调整控件布局时，用实际控件的玻璃局部归一化边界更新这些区域。霜纹按结霜面积排序生长，清晰区周边保留不规则的柔和过渡。
- **轮廓比例**在 src/shape.ts 配置宽度、长宽比和圆角。三种外壳共用同一个圆角矩形几何。
- **内置音乐**可以沿用 `src/config.ts` 的主题与曲目关联、`src/audio.ts` 的选曲和 `src/audioEngine.ts` 的播放与分析。将有权公开分发的音频和封面放到 `public/music/`，配置标题、作者、音频和封面地址，并在 `public/music/CREDITS.md` 记录素材来源、许可与署名。
- **本地音乐**文件选择器把音频交给 `src/audio.ts`，沿用 `src/musicDB.ts` 的 IndexedDB 数据库保存文件及主题分配，用 `src/preferences.ts` 管理选曲和音量偏好。曲库只保存在本机浏览器。
- **音乐响应**从 `src/audioEngine.ts` 的音乐分析节点输出四个归一化值传入 `src/musicEnergy.ts`。天气氛围音沿用 `src/ambience.ts` 的独立音频路径，节奏分析连接音乐输入。
- 在 `src/App.tsx` 继续分别管理背景主题、玻璃形状、材质参数、展开程度和播放状态。切换天气或形状时保留材质调节，天气、轮廓、音乐与上传分别提交 Git 记录。
