# github-notes

我的github的液态玻璃方案

## 液态玻璃材质实验台

在蓝青色曲面背景上观察圆角矩形玻璃的透射和边缘折射，并沿同一条深度轴展开六个材质层。页面由 React、TypeScript 和 Vite 构建，背景使用 Canvas 2D，玻璃使用 Three.js 的 WebGL 2 渲染、透视摄像机和三维薄侧壁。

### 运行

需要 pnpm 和 Node.js 20.19+（20.x），或 Node.js 22.12 及以上。在仓库根目录运行以下命令，打开终端显示的本地地址。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

构建会先运行 TypeScript 检查，再输出到 `dist/`。用预览命令检查构建产物。

```sh
pnpm build
pnpm preview
```

### 操作

- 舞台右上角可选择自动、浅色或深色材质，暂停或播放背景，以及复位全部参数。系统启用减少动态效果时，背景默认暂停，展开和合拢取消过渡。
- 在玻璃上按住鼠标并拖动可绕舞台中央旋转观察，六层随同一中心轴转动。触屏可直接拖动。聚焦玻璃后可用方向键旋转，按 `Home` 或双击恢复默认视角。
- 用「分层」和「合拢」切换视图，拖动「层间距」控制薄片的展开距离。点击列表里的层名或舞台上的薄片可查看该层说明与实时参数。「查看全部层」取消单层强调。
- 「显示采样点」呈现自动材质读取的 5×3 网格。关掉它即可恢复纯净的舞台视图。

| 层 | 作用 |
| --- | --- |
| 01 Shadow / 投影 | 透明平面下方的柔和投影 |
| 02 Blur & light / 模糊与提亮 | 用轻微模糊、饱和度和亮度调节透射背景 |
| 03 Rim lens / 边缘折射 | 将背景沿边缘向内采样，偏移和色散向中央衰减 |
| 04 Tint / 染色 | 由材质模式和浓度参数决定的半透明色膜 |
| 05 Rim light / 边缘光 | 左上沿主高光、右下沿次高光和内侧柔和倒角 |
| 06 Ink / 文字与图标 | 随局部明度切换墨色的标题、副标题与线性图形 |

### 渲染与坐标

背景 Canvas 是呈现、折射和明度采样共用的源。六个 Three.js 平面共享固定旋转轴和透视摄像机。着色器使用各平面的投影矩阵把局部几何坐标映射到舞台，再换算成原始背景纹理坐标。模糊层读取自身投影处的背景，折射层读取沿轮廓法线偏移后的纹理，保留边缘以内的中心透射。合拢时各层共面并露出一圈立体侧壁，分层时沿局部深度轴展开。染色、边缘光、投影和文字各自叠加。

自动材质从模糊层下方的 15 个投影点取样，剔除亮度极值后用均值调整材质。文字层在自己的投影位置独立读样，文字明暗切换有阈值缓冲。背景统计用于调节染色浓度和饱和度，像素颜色由原始背景纹理提供。

| 模块 | 职责 |
| --- | --- |
| `src/background.ts` | `createBackground` 管理 Canvas 的绘制、尺寸和时间坐标，接收低频、中频、高频及总能量，默认均为零 |
| `src/shape.ts` | `GLASS_SHAPES` 定义几何、轮廓和距离计算，提供侧壁、着色器和 CPU 命中测试所需的形状数据 |
| `src/projection.ts` | Three.js 透视摄像机、旋转、平面深度、视口适配和射线命中 |
| `src/material.ts` | 合拢和分层共用的默认参数、深浅模式和有效材质值 |
| `src/sampling.ts` | 根据投影生成 15 个点，读取背景亮度与色彩统计 |
| `src/glassRenderer.ts` | Three.js 光学平面与侧壁，以及随形状遮罩的可选表面纹理 |
| `src/GlassStage.tsx` | 舞台帧循环、展开动画、拖动和键盘旋转 |
| `src/App.tsx` | 背景主题、形状、材质、展开状态、背景播放和选层的状态入口 |
| `src/MaterialPanel.tsx` | 六层检查器、说明、间距和实时参数调节 |

### 后续扩展

- **天气背景**可从 `src/weather.ts` 恢复晴、阴、雨、雪的场景与粒子绘制，并把主题接入 `src/background.ts` 的背景源接口。让玻璃继续从该背景 Canvas 取样。雨滴、水痕、薄霜等贴在玻璃上的效果走 `src/glassRenderer.ts` 的独立表面位置，在同一个轮廓遮罩内绘制，并单独保存开关状态。
- **动物轮廓**从 `src/shape.ts` 的 `GLASS_SHAPES` 加入形状，例如猫咪、兔子或狗狗。形状提供尺寸以及 CPU 和着色器各自执行的距离计算。复杂轮廓可沿用旧版距离场思路，确保命中、折射、高光和遮罩使用同一轮廓。
- **内置音乐**可以沿用 `src/config.ts` 的主题与曲目关联、`src/audio.ts` 的选曲和 `src/audioEngine.ts` 的播放与分析。将有权公开分发的音频和封面放到 `public/music/`，配置标题、作者、音频和封面地址，并在 `public/music/CREDITS.md` 记录素材来源、许可与署名。
- **本地音乐**可以让文件选择器把音频交给 `src/audio.ts`，沿用 `src/musicDB.ts` 的 IndexedDB 数据库保存文件及主题分配，用 `src/preferences.ts` 管理选曲和音量偏好。曲库只保存在本机浏览器。
- **音乐响应**从 `src/audioEngine.ts` 的音乐分析节点输出四个归一化值，再交给背景和材质。天气氛围音沿用 `src/ambience.ts` 的独立音频路径，节奏分析只连接音乐输入。
- 在 `src/App.tsx` 继续分别管理背景主题、玻璃形状、材质参数、展开程度和播放状态。切换天气或形状时保留材质调节，天气、轮廓、音乐与上传分别提交 Git 记录。
